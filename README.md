# Git練習プロジェクト

このプロジェクトはGitの基本操作を学ぶためのサンプルです。

## ファイル構成

- `hello.py`: シンプルな挨拶アプリ
- `README.md`: このファイル（プロジェクトの説明）
- `.gitignore`: Gitで管理しないファイルの設定

## 実行方法

```bash
python hello.py
```

名前を入力すると挨拶が返ってきます。

## Gitの練習手順

### 1. プロジェクトフォルダの作成
新しいフォルダを作って、これらのファイルを保存してください。

### 2. Gitの初期化
Cursorでこのフォルダを開いて、Source Controlから「Initialize Repository」をクリック。

### 3. 最初のコミット
- ファイルをステージング（+ボタン）
- コミットメッセージを入力（例：「初回コミット」）
- ✓ボタンでコミット

### 4. ファイルを編集してみる
hello.pyを少し変更して、再度コミットしてみましょう。
